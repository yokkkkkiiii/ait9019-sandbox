# PDF Lecture Summarizer · PDF 课件总结器

## 用途
把课程 PDF（课件、讲义、tutorial notes）总结成便于复习的中文资料：**知识点类**给 50–60 字总摘要 + 清晰的分节讲解；**计划/待办类**给表格化行动清单与推荐顺序。输入课件通常为英文，输出统一用中文，重难点配中英对照。

## 何时使用
- 用户给出某一课件 PDF（或指出其在哪个文件夹），并要求总结、提炼要点、整理待办事项、讲解知识点、备考复习时。
- 典型说法："总结一下 week1 文件夹里的课件"、"把这份 PDF 做成笔记"。

## 工作流程

### 1. 定位并读取 PDF
- 用户通常告知文件所在文件夹：先按提示定位文件（必要时先列出该目录找出 .pdf）。
- 提取 PDF 文本（扫描版先 OCR），浏览页数/结构后再总结。

### 2. 先判断课件属于哪一类
- **A 类 · 计划/待办型**：内容主要是本周安排、checklist、任务清单、时间投入、截止日期（出现 "what to do this week"、"task/where/time" 表、"by the end of week…"、"acceptance" 等）。→ 走 3A
- **B 类 · 知识点型**：内容主要讲概念、原理、方法、术语、流程（其余课件均归此类）。→ 走 3B

### 3A. 计划/待办型 → 表格行动清单
- 用表格把"将要做的事"逐行列出。
- 表格必须包含：**事项**、**具体内容/步骤**、**预计时间**（课件有则填，没有可留空并注明"未给"）。
- 额外给出**推荐顺序**：说明先做什么、后做什么及理由；有截止日期的要明确提醒。

### 3B. 知识点型 → 总摘要 + 分节讲解
- 先给一段 **50–60 字的中文总体摘要**，覆盖课件核心内容。
- 再按章节/主题分节，用清晰易懂、有条理的话讲解知识点：
  - 语言：中文为主；**重难点/术语配英文原词对照**（如：向量数据库 Vector Database）
  - 解释通俗、口语化，必要时配简单例子。
  - 可标注页码（若有），方便回原课件定位。

### 4. 输出与核对
- 全篇输出中文；英文只出现在重难点对照中。
- 明确出现的数字（时间、日期、截止日）不能遗漏。
- 结构统一：知识点型必有 50–60 字摘要；待办型必有表格与推荐顺序。
